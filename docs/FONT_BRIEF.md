# Display typeface brief — Siargao Surf Camp

Prompt for Claude Design. Attach the **"CURRENTS OF DEVOTION" poster** as the
reference image (and optionally the "CALI, MEET CULTURE" collage as a secondary).

Whatever comes back as SVG gets compiled to `.ttf` / `.woff` and dropped into
`src/assets/fonts/`, replacing the placeholder faces currently generated by
`tools/build_fonts.py`.

---

## The prompt

> I need a custom **display typeface** drawn to match the lettering in the attached
> poster as closely as possible. It's for a Mad Monkey surf camp landing page in
> Siargao, Philippines — 1970s psychedelic surf-poster revival.
>
> **Match the reference lettering exactly.** Study the words "CURRENTS OF
> DEVOTION" in the image and reproduce that alphabet's logic:
>
> - **Uppercase only.** Every glyph is a capital.
> - **Liquid / poured construction.** Strokes swell dramatically at the middle of
>   each curve and pinch to narrow waists where they meet. Nothing is monoline —
>   the thick/thin rhythm is the whole personality.
> - **Bulbous, inflated bowls.** O, C, D, G, Q, S read as fat teardrops rather
>   than circles. Counters (the holes) are small, soft, off-centre ovals — the
>   letters are far more ink than air.
> - **Soft blunt terminals** that flare slightly outward as they end, like a
>   brushstroke lifting, occasionally curling back on itself.
> - **Wavy, organic contours.** No straight line stays perfectly straight — verticals
>   bow gently, crossbars undulate. Hand-poured, not geometric.
> - **Wide and tightly set.** Letters are broad and nearly touch; the alphabet is
>   built to lock into a dense block of type.
> - **Slightly irregular.** Letters shouldn't be perfectly repeatable — a little
>   variance in width and baseline is part of the look. Do NOT make it neat.
>
> Think Wes Wilson / Victor Moscoso psychedelic poster lettering crossed with
> melting soft-serve — not a rounded geometric sans, and not a bubble/graffiti face.
>
> ### Glyphs required
>
> - `A–Z` (26)
> - `0–9` (10)
> - `. , : ; ! ? ' " & - – — / ( ) + % # @ ₱`
>
> The peso sign `₱` matters — prices on the page are ₱48,000 and ₱28,000.
>
> ### Technical spec (please follow exactly — these go into a real font file)
>
> - **One SVG per glyph**, named `U+0041.svg`, `U+0042.svg` … (or `A.svg`, `B.svg`).
> - **`viewBox="0 0 1000 1000"` on every glyph**, same coordinate system throughout.
> - **Baseline at y = 800.** Cap height 700, so capitals span y=100 (top) to y=800.
> - **Left sidebearing ~70 units**; note each glyph's intended advance width in the
>   filename or a sidecar list (e.g. `A 640`). Default 600.
> - **Filled closed paths only** — `fill="#000000"`, no `stroke`, no `transform`,
>   no `<g>`, no clip paths, no gradients, no text elements.
> - **Counters as separate subpaths** in the same `<path>`, wound opposite to the
>   outer contour so they punch through.
> - Single weight. No italic.
>
> ### Also produce
>
> A specimen sheet rendering these exact strings, so I can check the fit:
>
> - `WARM WATER, GOOD WAVES, ZERO HASSLE.`
> - `SPOTS PICKED DAILY`
> - `NO HIDDEN COSTS`
> - `ALL THE GOOD VIBES`
> - `GET IN THE WATER`
> - `₱48,000` and `7 DAYS / 6 NIGHTS`
>
> Set in cream `#FBF6F3` on a yellow `#F1D46C` and coral `#FC8C5C` ground — that's
> where it'll actually live, so it has to hold up there.

## Notes for me (Claude Code) when the files come back

- Compile with a new SVG→glyf path (`fontTools.svgLib.SVGPath` → `TTGlyphPen`),
  reusing the metrics and name-table setup already in `tools/build_fonts.py`.
- Flip the y-axis: SVG is y-down, font units are y-up — `y_font = 800 - y_svg`.
- Keep the family name `Siargao Liquid` so `tailwind.config.ts` and the
  `@font-face` blocks in `src/index.css` need no changes.
- The current `Siargao Block` face can stay as-is for section headings, or get a
  matching second cut if the new drawing suggests one.
